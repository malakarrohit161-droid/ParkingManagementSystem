# TQM-Based Parking Management System

A desktop Parking Management System developed using Python, Tkinter and SQLite.

## Project Objective

The objective of this project is to apply Total Quality Management (TQM)
principles to a parking management process.

The system focuses on preventing errors and reducing duplicate parking
entries through validation and quality-control mechanisms.

## Quality Goals

- Reduce duplicate entries
- Prevent invalid data
- Improve data accuracy
- Standardize the vehicle entry and exit process
- Improve reliability
- Support continuous improvement

## Core Quality Features

1. Unique ID constraints
2. Pre-add validation
3. Search before add
4. Confirmation dialogs
